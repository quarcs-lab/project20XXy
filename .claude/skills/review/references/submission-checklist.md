# Manual Submission Checklist

> Part of the `review` skill. These are human-action items the automated
> dimensions in `audit-checklist.md` cannot verify. Include them as an unchecked
> list in the manuscript-scope review report so the author can confirm each.

## Before submitting

- [ ] **Target journal/venue selected**, and the manuscript matches its scope.
- [ ] **Formatting matches the venue** (template, section order, reference style).
- [ ] **Word/page limit** confirmed against the venue (the audit reports the count;
      the limit is venue-specific).
- [ ] **Abstract** present, within the venue's word limit, and self-contained.
- [ ] **Keywords** and **JEL codes** (if economics) filled in.
- [ ] **Data availability statement** written (where the data live, access terms).
- [ ] **Code/replication availability** stated (repo or archive link).
- [ ] **Acknowledgments** reviewed — and **removed/anonymized** if the venue is
      double-blind.
- [ ] **Author metadata** (names, affiliations, ORCID, corresponding author,
      emails) complete in the `index.qmd` YAML.
- [ ] **Funding/grant numbers** disclosed if required.
- [ ] **Ethics / IRB / conflict-of-interest** statements included if required.
- [ ] **All `[FILL:]` and `[CITE:]` placeholders resolved** (the audit flags any
      remaining; confirm none are left).
- [ ] **PDF renders cleanly** end-to-end (`/project:render`) with no broken
      references, figures, or tables.
- [ ] **Supplementary materials / appendix** prepared and referenced.
- [ ] **Cover letter** drafted (if the venue requests one).

## Double-blind specifics (if applicable)

- [ ] No author names in the body, headers, or file metadata.
- [ ] Self-citations phrased in the third person ("Smith (2020) shows…", not
      "in our earlier work").
- [ ] No identifying acknowledgments, institutions, or repository URLs in the body.
