## Work completed

- **Added Critical Rule #5 to `CLAUDE.md`:** "Ask before coding — Before implementing any change, ask clarifying questions until you are 95% confident you understand exactly what is needed. Do not make assumptions about scope, approach, or intent."
- **Phase 1 — Metadata update (24 skills):** Added `version: 1.0.0`, `workflow_stage`, and `tags` YAML fields to all 24 existing SKILL.md files. Skills organized by 7 workflow stages: setup, data, analysis, writing, communication, quality, session.
- **Phase 2 — Enhanced 4 existing skills:**
  - `draft-section` — Added IMRAD section templates (Introduction, Data/Strategy, Results, Conclusion), economics writing conventions (causal vs. associational language, hedging, economic significance), Common Pitfalls, and References (Cochrane, Shapiro, Thomson, Nikolov).
  - `new-analysis` — Added deeper method-specific guidance: staggered DiD warnings with Bacon decomposition, weak IV diagnostics (F>10, Kleibergen-Paap, Anderson-Rubin CIs), RDD McCrary test and CCT optimal bandwidth, Panel FE within-R² distinction. Added language-specific package tables (pyfixest, fixest, reghdfe, rdrobust, csdid, etc.), Common Pitfalls, and References.
  - `regression-table` — Added AER-style LaTeX formatting: booktabs rules only, threeparttable notes, multi-panel support, siunitx alignment, compact formatting. Added Common Pitfalls.
  - `literature-note` — Added "Limitations and Critiques" and "Citation Network" sections to the note template. Added cross-referencing step to scan existing notes for connections. Added Common Pitfalls.
- **Phase 3 — Created 3 new skills:**
  - `/project:lit-review` — Systematic literature review with search strategy design, paper inventory table, thematic synthesis, gap identification, integration with `/project:cite` and `/project:literature-note`.

  - `/project:econ-visualization` — Publication-quality figure templates for 8 chart types (coefficient plot, event study, RD plot, time series, scatter, distribution, bar, heatmap) with colorblind-safe palettes and journal-ready styling.
- **Phase 4 — Updated `CLAUDE.md`:** Added 3 new skills to skill reference tables, reorganized "References & Data" into "Research & Literature" category, updated skill count from 24 to 27.
